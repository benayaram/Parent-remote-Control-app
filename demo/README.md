# Dashboard walkthrough

The video is an authored Remotion UI prototype with synthetic data. It illustrates the intended parent dashboard, sampled reports, capability boundaries, and child-started local check-ins. It is not footage of either Android app, and does not prove device enforcement or Firebase/Mongo connectivity.

Reproduce: `cd walkthrough && npm ci && npm run dev` for Studio, or `npm run render`. The checked-in MP4 is `familyguard-demo.mp4`. All data is fictional. No camera, microphone, location, child account, or production service was accessed during rendering.

The Remotion scaffold was retrieved from the official `remotion-dev/remotion` template-blank source after create-video could not use the environment proxy. Runtime package versions are pinned in package-lock.json.
