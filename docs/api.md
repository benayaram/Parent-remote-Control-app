# API v1
Parent: Firebase Bearer token; verified email and nonrevoked family membership. Child: x-device-id, x-device-time (epoch milliseconds), x-device-nonce (UUID), x-device-signature (base64 DER ECDSA).
Signing input: METHOD + newline + exact original URL including query + newline + time + newline + nonce + newline + hex SHA256(raw UTF-8 request body). Empty body hashes empty string.
Routes: POST /families; GET /families/:id; POST /pairing/sessions; POST /pairing/claim (child disclosure/key); POST /pairing/confirm (recently authenticated family parent); GET /devices/:id; GET/PUT /devices/:id/policy; GET/POST /devices/:id/commands; POST /commands/:id/ack; POST /devices/:id/heartbeat; GET/POST /devices/:id/usage; GET/POST /devices/:id/location; POST /devices/:id/sos; POST /devices/:id/time-requests; POST /time-requests/:id/decision; GET /families/:id/alerts; POST /devices/:id/revoke; POST /families/:id/export; DELETE /families/:id/data.
All collection reads bounded. Location default TTL 48h, usage 30d. Parent command type allowlist excludes camera/audio/remote shell. Command ack must belong to signing device and pending/delivered state; terminal repeats are idempotent, conflicting results reject.
