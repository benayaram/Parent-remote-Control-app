# Permissions and revocation
Parent: INTERNET only. Child: INTERNET, PACKAGE_USAGE_STATS (Settings app-op), ACCESS_COARSE_LOCATION/ACCESS_FINE_LOCATION (foreground user request), POST_NOTIFICATIONS (API 33+), CAMERA and RECORD_AUDIO (only inside child-started activity), device admin receiver BIND_DEVICE_ADMIN with force-lock policy. No QUERY_ALL_PACKAGES, background location, accessibility service, MediaProjection, SMS, call logs, notification listener or boot persistence.
Declining usage or location yields permission_required and no invented samples. Camera/microphone are requested separately for the chosen local action; denial never enrolls or activates capture. Leaving capture stops recording, deletes unshared microphone file on exit; photo opens system camera app and stays in child-private storage. No media upload exists. Device admin activation uses system consent UI.
Google Play monitoring-tool declaration: child_monitoring. Production requires Data Safety, privacy policy and monitoring-app policy review. Manifest source audit is not a substitute for auditing merged release manifests/dependencies.
