# Deployment
Use Node 24 and MongoDB 7+ replica set (transactions required). Configure MONGODB_URI, FIREBASE_PROJECT_ID and Application Default Credentials outside source control. Copy backend/.env.example for names only; never commit secrets. Run npm ci, npm run build, npm start in backend. Terminate TLS at a trusted reverse proxy; keep API loopback/internal behind it, or set HOST deliberately. Restrict egress to Firebase Auth/FCM and your database; never disable TLS verification.
Firebase: enable email/password, configure Android apps com.familyguard.parent / com.familyguard.child, pass Firebase options via Dart defines documented in apps/README.md. Verify email before family setup. FCM credentials belong only on backend; push transport needs registration integration before production use.
No Firebase/Atlas credentials or eligible hardware were provided. No deployment or end-to-end mobile account flow is claimed. Review and publish environment configuration only after validating required gates.
