# Deployment

Use Node 24 and MongoDB 7+ replica set (transactions required). Configure MONGODB_URI, FIREBASE_PROJECT_ID, FIREBASE_STORAGE_BUCKET and Application Default Credentials outside source control. Copy backend/.env.example for names only; never commit secrets. Run npm ci, npm run build, npm start in backend. Terminate TLS at a trusted reverse proxy; keep API loopback/internal behind it, or set HOST deliberately. Restrict egress to Firebase Auth/FCM and your database; never disable TLS verification.
Firebase: enable email/password, configure Android apps com.familyguard.parent / com.familyguard.child, pass Firebase options via Dart defines documented in apps/README.md. Verify email before family setup. Admin credentials belong only on backend. Configure native google-services.json in both apps (ignored), register routing tokens through authenticated endpoints, and test FCM delivery. See firebase/README.md for private Storage rules and cleanup.
No Firebase/Atlas credentials or eligible hardware were provided. No deployment or end-to-end mobile account flow is claimed. Review and publish environment configuration only after validating required gates.
