# Product requirements

FamilyGuard is a transparent Android family supervision platform. Parent and child apps share contracts; the child sees supervision, permission state, policy, SOS, and requests. Standard mode offers reports/reminders, never guaranteed app blocking. Managed policies require genuine device owner eligibility. Emergency calling and accessibility must remain available. No covert monitoring, private communications, screenshots, keystrokes, arbitrary commands or credential collection.
The user's revised camera/microphone requirement is constrained to child-started local capture; each session is visible and ends when leaving its screen. No parent activation endpoint exists. Production launch requires guardian/age/legal review and real hardware validation.
